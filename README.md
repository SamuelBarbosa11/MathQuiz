# QuizMath - Principio da Contagem (adição, multiplicação e Casa dos Pombos) para Ensino Médio

Esse é um projeto da cadeira de Resolução de problemas de natureza discreta feito pela minha equipe do curso de Ciência da Computação (3° semestre) da Unifor com o objetivo de testar os conhecimentos sobre os Principios da Contagem de alunos do Ensino Médio por meio de um Quiz elaborado com HTML, CSS e JavaScript.
O projeto será exibido na Feira das Profissões na Unifor nos dias 14/05 e 15/05 de 2026
